# Mermaid Diagrams

Create and maintain the following diagrams from repository evidence. Mermaid source can live in `.mmd` files and can also be rendered by compatible tools.

1. `architecture.mmd` — high-level components and dependencies.
2. `request-flow.mmd` — relevant existing request/data flow for the exercise.
3. `task-options.mmd` — compare the three task paths and show that exactly one is selected.
4. `test-strategy.mmd` — test layers and the selected task's verification flow.

Rules:
- Use Mermaid syntax only in `.mmd` files.
- Do not invent components or connections; label uncertain details as unknown in `docs/ASSESSMENT.md`.
- Diagrams are working aids, not substitutes for explanatory notes.
- Update task-specific diagrams after task selection if the first version is generic.
