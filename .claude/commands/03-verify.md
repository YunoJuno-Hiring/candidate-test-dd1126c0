# Stage 03 — Verify

Read the selected task's acceptance criteria and test strategy. Discover and run the relevant commands supported by the repository:
- backend tests
- frontend tests
- lint/type checking
- frontend build
- relevant integration or smoke checks, if the environment supports them

Record exact commands, outcomes, and limitations in `docs/REVIEW_REPORT.md`. Separate baseline failures from regressions. Inspect important edge cases and failure paths. Never claim a check passed if it was not run. Do not commit or push.
